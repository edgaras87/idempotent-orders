# knowledge.log.md

Decisions, not touches. Only the last entry is soft — refinements fold into it; the next
entry freezes it. Frozen entries are never rewritten; corrections and reversals are new
entries referencing the old. Consult by entry, not end-to-end. (Full rule:
`knowledge.vision.md`.)

**0001 — Working node born from the workbench's knowledge seed.** Fresh working node for
this repo's project: the workbench's `knowledge/` dir copied whole as this repo's
`internals/knowledge/` — the node's four docs plus the shipped knowledge branches
(`core/`, `realization/`), names final, nothing renamed. The project is deliberately
undefined; its problem artifacts and the problem's own record (`log.md`, `status.md` at
`internals/` root) are earned when problem work starts — everything beyond this node's
four docs is earned by need. The shipped branches are this project's **working fork** of
the workbench masters (amendable under this node's law; `fork.log.md` born at the first
deviation — see the vision). One role: **steward**, sole writer of both planes'
artifacts. Logs are per-repo and never inherited: this log starts here; the workbench's
log records the seed's own history. Earlier work, if any exists, reaches this node only
through the human, as ordinary input.

**0004 — Thinker-role question deferred at its named trigger; the steward keeps both
planes.** The definition step is the question's earliest natural trigger
(`knowledge.status.md` carried it there); judged now on the lived evidence: two data
points — the intent step and the definition's evaluation both worked in session by the
steward without strain — and none of the strain the narrow-roles hypothesis predicts
(context competing, the planes crowding one conversation) has appeared. Decision:
**defer, not discard** — the steward continues as sole writer of both planes; the split
is re-judged at the **registry's birth or the first slice**, whichever first shows

Cheap to reverse: enacting the split later costs a lens and a log entry; enacting it
now, ahead of strain, would be role-creation ahead of need against the vision's own
rule.

**0006 — Thinker-role question re-judged at the registry's birth; deferred, with a
sharpened expectation.** Entry 0004 named two judgment points; the first is reached
and checked deliberately. The chain's three inner steps have now run in session

project's scope is a single service**, the L2 system of interest deliberately small
